# 🛍️ Baby Clothes Backend (Refactor)

Đây là cửa hàng bán quần áo trẻ em được xây dựng cách đây 2 năm và đang refactor với **ExpressJS - 2025**. Dự án đã hỗ trợ các tính năng cơ bản như quản lý sản phẩm, người dùng, đơn hàng, giỏ hàng và sẽ được update lại với code mới nhất kèm theo các tính năng mới.

---

## 🧱 Công nghệ sử dụng

- [ExpressJS](https://expressjs.com/) – Framework for Node.js
- [MongoDB](https://www.mongodb.com/) – Non-Relational database management system
- [Docker](https://www.docker.com/) (Add docker soon)

- Start dev: `npm run start:dev`
